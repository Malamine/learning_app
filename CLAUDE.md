# Custom Quiz — PWA

## Project Context
A Progressive Web App (PWA) for reviewing the book **"Fluent Python" by Luciano Ramalho** (2nd edition, ~900 pages).

The user reads the book chapter by chapter and wants to be quizzed daily on what they have learned, via an interactive chat powered by an LLM.

---

## Tech Stack
- **Frontend**: HTML + CSS + vanilla JavaScript (single file `index.html`)
- **LLM**: Google Gemini API (`gemini-2.0-flash` — free up to 1,500 req/day)
- **PDF**: Client-side reading via `PDF.js` (Mozilla)
- **PWA**: `manifest.json` + Service Worker for mobile installation
- **Storage**: `localStorage` for history and progress tracking

---

## Features to Build

### 1. PDF Chapter Upload
- The user uploads a chapter (or section) of the book as a PDF
- Text is extracted client-side using PDF.js
- The extracted text is sent to Gemini as context

### 2. Question Generation by Gemini
- Gemini reads the chapter content
- It generates 3 to 5 varied questions (open-ended, code completion, concept explanation)
- Questions focus exclusively on the content of the uploaded chapter

### 3. Multiple-Choice Quiz Interface
- Each question has 4 options, generated by Gemini as structured JSON (one correct, three plausible distractors)
- Selecting an option grades instantly (no extra API call) and shows Gemini's explanation
- Tone is pedagogical, encouraging, and precise
- A "🤔 Ask first" mode lets the user request a clarifying hint (free text) before picking an answer

### 3b. Built-in reference guides
- `builtin-books.js` bundles thematic reference material as ready-to-use books, no PDF upload required. Currently: Python Best Practices (PEP 8/20/257), Testing with Pytest & Mock (fixtures, parametrize, marks, unittest.mock/patch), Concurrency: Threading & Multiprocessing, Decorators & Python Syntax (PEP 318, functools)
- Each chapter is a theme (e.g. "unittest.mock — patch() Basics") with pre-extracted, cleaned text sourced from official docs (docs.python.org, pytest docs, PEPs), works fully offline
- To add another built-in guide, append an entry to `BUILTIN_BOOKS` in `builtin-books.js` with `{id, name, chapters: [{title, text}]}`

### 3c. Weak spots — spaced repetition (Leitner system)
- Missed questions are stored with their full MCQ (options/correct/explanation) so they can be replayed, not just the text
- Each weak spot has a `box` (0–4) and `nextReviewAt`; answering correctly during a weak-spot review advances the box and pushes the next-due date out (1, 2, 4, 9, 18 days); missing it again resets to box 0
- A spot graduates (is removed) after being answered correctly at the last box — this is what makes review durable instead of "seen once, forgotten"
- `launchWeakSession` always sorts by soonest-due first, so pressing "Weak spots" never dead-ends even if nothing is strictly due yet

### 4. Progress Tracking
- Session history saved in localStorage
- Score per chapter
- Summary view of already reviewed chapters

### 5. Mobile-Installable PWA
- `manifest.json` with icon and app name
- Basic Service Worker for offline support (static cache)
- Responsive design, usable on smartphone

## Gemini API Configuration

The user enters their Gemini API key directly in the interface (stored in localStorage).

- Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent`
- Free key available at: https://aistudio.google.com/app/apikey
- Free tier limits: 1,500 requests/day, 15 requests/minute

---

## System Prompt for Gemini

```
You are a pedagogical assistant and Python expert, specialized in the material
being studied (a book chapter or a reference guide like PEP 8).

When provided with an excerpt:
1. Generate 3 to 5 varied multiple-choice questions about the content, each with
   exactly 4 options (one correct, three plausible distractors)
2. Mix question types: theoretical concepts, code examples, practical use cases
3. Provide a short explanation of why the correct option is right
4. Use Python code examples when relevant
5. Stay focused on the content of the provided excerpt
6. Respond only with structured JSON (no prose, no markdown fences)

Always reply in English.
```
